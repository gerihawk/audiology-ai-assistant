firmados con proveedores externos — evidencia de cumplimiento para
[privacy-and-security.md](../privacy-and-security.md) §9.

terceros): solo este `README.md` y `.gitkeep` van al repositorio, ver
`.gitignore`. Los PDFs viven únicamente en este equipo — si hace falta
compartirlos (auditoría, due diligence de venta), se envían aparte.
